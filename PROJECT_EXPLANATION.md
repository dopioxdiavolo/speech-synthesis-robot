## 🎯 Что мы сделали

Мы создали **мультимодальную систему синтеза речи для социального робота**, которая объединяет:

1. **Физиологически обоснованную модель голосовых связок** - генерирует источник звука с управляемыми параметрами
2. **Визуализацию мимики робота** - показывает состояние экспрессии в реальном времени
3. **Контроллер поведения** - координирует голос и мимику для создания согласованного выражения

### Ключевые достижения:

- ✅ Модель голосовых связок с физиологическими параметрами (F0, jitter, shimmer, phonation type)
- ✅ Визуализация мимики через matplotlib, pygame, ASCII-арт
- ✅ Автоматическое определение эмоций из текста
- ✅ Координация голоса и мимики через BehaviorController
- ✅ Интеграция с TTS для качественной речи
- ✅ Учёт внутреннего состояния робота (energy, stress, mood)

## 🧠 Модели и их функции

### 1. VocalFoldsModel (`vocal_folds.py`)

**Что делает:** Генерирует источник звука (source) для source-filter модели с физиологически обоснованными параметрами.

**Параметры:**

| Параметр | Описание | Физиологический смысл | Типичные значения |
|----------|----------|----------------------|-------------------|
| **F0** | Fundamental frequency | Частота вибрации голосовых связок | 100-250 Гц |
| **Jitter** | Вариабельность F0 | Микро-вариации частоты между циклами | 0.5-1.5% |
| **Shimmer** | Вариабельность амплитуды | Микро-вариации амплитуды между циклами | 3-5% |
| **Phonation Type** | Тип фонации | Степень смыкания голосовых связок | modal/breathy/pressed |
| **Vocal Effort** | Усилие фонации | Подглоточное давление воздуха | 0.5-2.0 |

**Где используется:**
- `speech_synthesizer.py` → `_synthesize_with_f0_contour()` - при синтезе гласных
- `speech_synthesizer.py` → `_apply_prosody_to_tts_audio()` - при применении параметров к TTS аудио

**Пример использования:**
```python
from vocal_folds import VocalFoldsModel, PhonationType

model = VocalFoldsModel(sample_rate=16000)
source = model.generate_source(
    duration=1.0,
    f0=150.0,
    jitter=0.01,  # 1%
    shimmer=0.03,  # 3%
    phonation_type=PhonationType.MODAL
)
```

### 2. FacialExpressionRenderer (`facial_expression.py`)

**Что делает:** Визуализирует состояние мимики робота в реальном времени.

**Состояния мимики:**

| Состояние | Описание | Параметры |
|-----------|----------|-----------|
| **neutral** | Нейтральное выражение | Нормальные глаза, прямая линия рта |
| **friendly** | Дружелюбное | Счастливые глаза, улыбка, приподнятые брови |
| **strict** | Строгое | Узкие глаза, хмурый рот, нахмуренные брови |
| **warning** | Предупреждение | Широкие глаза, открытый рот, высоко поднятые брови |

**Методы визуализации:**

1. **matplotlib** - детальная графическая визуализация
   - Сохраняет PNG файлы в `facial_expressions/`
   - Показывает окно с детальной отрисовкой лица
   - Требует: `pip install matplotlib`

2. **pygame** - интерактивная анимация
   - Открывает интерактивное окно
   - Плавная анимация переходов
   - Требует: `pip install pygame`

3. **ascii** - ASCII-арт в терминале
   - Текстовое представление
   - Работает везде, не требует установки

4. **emoji** - простые смайлики
   - Быстрая визуализация
   - Не требует установки

**Где используется:**
- `speech_synthesizer.py` → `synthesize_phrase()` - визуализация при синтезе
- `multimodal_demo.py` - демонстрация всех состояний

**Пример использования:**
```python
from facial_expression import FacialExpressionRenderer, ExpressionState

renderer = FacialExpressionRenderer(render_method='matplotlib')
renderer.set_expression(ExpressionState.FRIENDLY)
renderer.render()  # Показывает визуализацию
```

### 3. BehaviorController (`behavior_controller.py`)

**Что делает:** Координирует состояние голоса и мимики на основе стиля речи и внутреннего состояния робота.

**Входные параметры:**

- **style** (str): стиль речи - 'neutral', 'friendly', 'strict', 'warning'
- **internal_state** (dict, опционально):
  - `energy` (float): уровень энергии робота (0.0-2.0)
  - `stress` (float): уровень стресса (0.0-1.0)
  - `mood` (str): настроение - 'positive', 'negative', 'neutral'

**Выходные параметры:**

- **voice_params** (dict): параметры голосовых связок
  - `f0_base`: базовая частота F0
  - `jitter`: вариабельность F0
  - `shimmer`: вариабельность амплитуды
  - `phonation_type`: тип фонации
  - `vocal_effort`: усилие фонации

- **facial_state** (ExpressionState): состояние мимики

**Логика координации:**

```python
# Пример маппинга стилей:
'friendly' → {
    voice: F0=180Hz, modal phonation, высокий vocal_effort
    facial: ExpressionState.FRIENDLY (улыбка)
}

'strict' → {
    voice: F0=120Hz, pressed phonation, низкий jitter
    facial: ExpressionState.STRICT (хмурое лицо)
}
```

**Где используется:**
- `speech_synthesizer.py` → `synthesize_phrase()` - вычисление параметров поведения
- `multimodal_demo.py` - демонстрация влияния внутреннего состояния

**Пример использования:**
```python
from behavior_controller import BehaviorController

controller = BehaviorController()
voice_params, facial_state = controller.compute_behavior(
    style='friendly',
    internal_state={'energy': 1.5, 'stress': 0.1}
)
```

### 4. SpeechSynthesizer (`speech_synthesizer.py`)

**Что делает:** Главный модуль, объединяющий все компоненты для синтеза речи.

**Основные методы:**

1. **`synthesize_phrase()`** - синтез фразы с мимикой
   ```python
   audio, facial_state = synthesizer.synthesize_phrase(
       "Привет!",
       style='friendly',
       show_facial_expression=True
   )
   ```

2. **`synthesize_with_prosody_transfer()`** - синтез с переносом просодии
   ```python
   audio = synthesizer.synthesize_with_prosody_transfer(
       "Новая фраза",
       reference_audio='reference.wav'
   )
   ```

**Внутренние методы:**

- `_synthesize_with_f0_contour()` - синтез с использованием VocalFoldsModel
- `_apply_prosody_to_tts_audio()` - применение параметров голосовых связок к TTS аудио
- `_detect_emotion_from_text()` - определение эмоции из текста

---

### 5. ArticulatoryModel (`articulatory_model.py`)

**Что делает:** Реализует source-filter модель речевого тракта.

**Компоненты:**

- **Source (источник):**
  - `generate_voice_source()` - периодический сигнал (голосовые связки)
  - `generate_noise_source()` - шумовой сигнал (согласные)

- **Filter (фильтр):**
  - `create_formant_filter()` - формантные резонаторы (F1, F2, F3)
  - `synthesize_vowel()` - синтез гласного звука

**Где используется:**
- `speech_synthesizer.py` - базовый синтез (если не используется TTS)
- Интегрируется с VocalFoldsModel для более реалистичного источника

---

### 6. ProsodyController (`prosody_controller.py`)

**Что делает:** Управляет просодическими параметрами речи.

**Параметры:**

- **F0 contour** - контур интонации (мелодия)
- **Energy contour** - контур громкости
- **Duration factor** - фактор длительности (темп)
- **Pause duration** - длительность пауз

**Где используется:**
- `speech_synthesizer.py` - генерация просодических контуров
- Применение к синтезированному аудио

## 📚 Глоссарий терминов

### Физиологические термины:

**F0 (Fundamental Frequency)**
- **Что это:** Основная частота вибрации голосовых связок
- **Единицы:** Герцы (Гц)
- **Типичные значения:** 100-250 Гц (мужской голос: 100-150 Гц, женский: 150-250 Гц)
- **Физический смысл:** Зависит от длины, массы и натяжения голосовых связок, а также от подглоточного давления воздуха
- **В коде:** `vocal_folds.py` → `generate_source(f0=150.0)`

**Jitter**
- **Что это:** Вариабельность F0 между циклами вибрации
- **Единицы:** Проценты (%)
- **Типичные значения:** 0.5-1.5% (нормальная речь)
- **Физический смысл:** Отражает естественные микро-вариации из-за нелинейной динамики голосовых связок
- **Повышенный jitter:** Может указывать на патологию или эмоциональное состояние (стресс, напряжение)
- **В коде:** `vocal_folds.py` → `generate_source(jitter=0.01)` (1%)

**Shimmer**
- **Что это:** Вариабельность амплитуды между циклами вибрации
- **Единицы:** Проценты (%)
- **Типичные значения:** 3-5% (нормальная речь)
- **Физический смысл:** Отражает изменения амплитуды вибрации из-за вариаций в потоке воздуха и натяжении связок
- **Повышенный shimmer:** Связан с напряжением или патологией
- **В коде:** `vocal_folds.py` → `generate_source(shimmer=0.03)` (3%)

**Phonation Type (Тип фонации)**
- **Что это:** Способ вибрации голосовых связок, определяемый степенью их смыкания
- **Типы:**
  - **Modal (модальная):** Нормальная фонация, полное смыкание связок, богатый спектр
  - **Breathy (придыхательная):** Неполное смыкание связок, больше шума, менее эффективная фонация
  - **Pressed (сжатая):** Избыточное смыкание связок, напряжённый звук, более резкий
- **Физический смысл:** Зависит от степени смыкания голосовых связок и давления воздуха
- **В коде:** `vocal_folds.py` → `PhonationType.MODAL`

**Vocal Effort (Усилие фонации)**
- **Что это:** Усилие, прилагаемое для производства звука
- **Единицы:** Безразмерная величина (0.0-2.0)
- **Типичные значения:** 1.0 (нормальное усилие)
- **Физический смысл:** Большее усилие → большее подглоточное давление → большая амплитуда и более богатый спектр
- **В коде:** `vocal_folds.py` → `generate_source(vocal_effort=1.0)`

### Модельные термины:

**Source-Filter Model (Source-Filter модель)**
- **Что это:** Физиологически обоснованная модель производства речи
- **Компоненты:**
  - **Source (источник):** Вибрация голосовых связок + турбулентный шум
  - **Filter (фильтр):** Резонансные свойства речевого тракта (форманты)
- **Физический смысл:** Соответствует реальному процессу производства речи у человека
- **В коде:** `articulatory_model.py` → `ArticulatoryModel`

**Formants (Форманты)**
- **Что это:** Резонансные частоты речевого тракта
- **Обозначения:** F1, F2, F3 (первые три форманты)
- **Единицы:** Герцы (Гц)
- **Физический смысл:**
  - **F1:** Связан с высотой языка (вертикальное положение)
  - **F2:** Связан с передне-задним положением языка
  - **F3:** Связан с формой глотки и ротовой полости
- **В коде:** `articulatory_model.py` → `VOWEL_FORMANTS`

**Prosody (Просодия)**
- **Что это:** Надсегментные характеристики речи (интонация, ритм, ударение)
- **Компоненты:**
  - **F0 contour:** Контур интонации (мелодия)
  - **Energy contour:** Контур громкости
  - **Duration:** Длительность сегментов
  - **Pauses:** Паузы между сегментами
- **В коде:** `prosody_controller.py` → `RuleBasedProsodyController`

---

### Технические термины:

**TTS (Text-to-Speech)**
- **Что это:** Технология синтеза речи из текста
- **В проекте:** Используется Edge TTS (Microsoft) для качественного синтеза
- **В коде:** `speech_synthesizer.py` → `use_tts=True`

**Sample Rate (Частота дискретизации)**
- **Что это:** Количество отсчётов сигнала в секунду
- **Единицы:** Герцы (Гц)
- **Типичные значения:** 16000 Гц (16 кГц) - стандарт для речи
- **В коде:** `SpeechSynthesizer(sample_rate=16000)`

**Expression State (Состояние экспрессии)**
- **Что это:** Состояние мимики робота
- **Типы:** neutral, friendly, strict, warning
- **В коде:** `facial_expression.py` → `ExpressionState`

**Behavior Controller (Контроллер поведения)**
- **Что это:** Модуль, координирующий голос и мимику
- **Функция:** Вычисляет параметры голоса и мимики на основе стиля речи
- **В коде:** `behavior_controller.py` → `BehaviorController`
