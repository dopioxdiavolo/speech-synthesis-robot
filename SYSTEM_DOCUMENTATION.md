## 🎯 Обзор системы

### Что это?

Система синтеза речи для социальных роботов, которая:
- **Синтезирует речь** из текста с естественным голосом
- **Автоматически определяет эмоции** из текста с помощью ML модели
- **Управляет просодией** (интонация, темп, громкость) для передачи эмоций
- **Использует биомиметическую модель** речевого тракта (source-filter)

### Основные возможности

✅ **Автоматическое определение эмоций** - система сама понимает, какую эмоцию передать  
✅ **Естественный голос** - интеграция с TTS моделями (Edge TTS, Bark, и др.)  
✅ **Управление просодией** - контроль над интонацией, темпом, громкостью  
✅ **Биомиметическая модель** - имитация работы человеческого речевого тракта  
✅ **Перенос просодии** - возможность копировать интонацию из референсной речи

## 🔧 Компоненты системы

### 1. EmotionDetector (`emotion_detector.py`)

**Назначение:** Автоматическое определение эмоций из текста

**Методы работы:**

#### ML модель (основной)
- Использует предобученную модель `cointegrated/rubert-tiny-sentiment`
- Анализирует тональность текста (positive/negative/neutral)
- Маппит результаты на стили системы:
  - `positive` → `friendly`
  - `negative` → `strict` или `warning` (по контексту)
  - `neutral` → `neutral`

#### Rule-based (fallback)
- Анализ ключевых слов
- Анализ пунктуации (!, ?, ...)
- Анализ заглавных букв
- Контекстный анализ

**Возвращает:**
- Стиль: `'neutral'`, `'friendly'`, `'strict'`, `'warning'`
- Уверенность: `0.0 - 1.0`

---

### 2. TTS Integration (`tts_integration.py`)

**Назначение:** Интеграция различных TTS моделей для естественного голоса

**Поддерживаемые движки:**

#### Edge TTS (Microsoft) - рекомендуется
- ✅ Качественный голос
- ✅ Бесплатный
- ✅ Поддержка эмоций через выбор голоса
- ✅ Требует интернет

**Голоса по эмоциям:**
- `friendly` → `ru-RU-SvetlanaNeural` (женский, дружелюбный)
- `strict` → `ru-RU-DmitryNeural` (мужской, строгий)
- `warning` → `ru-RU-DariyaNeural` (женский, предупреждающий)
- `neutral` → `ru-RU-SvetlanaNeural` (по умолчанию)

#### Bark (Suno AI)
- ✅ Очень выразительный
- ✅ Поддержка эмоций через теги
- ⚠️ Требует больше ресурсов

#### Другие
- Google TTS (gTTS)
- Silero TTS (offline)
- pyttsx3 (offline, низкое качество)

---

### 3. ProsodyController (`prosody_controller.py`)

**Назначение:** Управление просодическими параметрами речи

**Параметры стилей:**

| Стиль | F0 (Гц) | Темп | Громкость | Паузы |
|-------|---------|------|-----------|-------|
| `neutral` | 150-170 | Средний | Средняя | 0.1 сек |
| `friendly` | 180-200 | Быстрый | Высокая | 0.05 сек |
| `strict` | 120-140 | Медленный | Низкая | 0.2 сек |
| `warning` | 160-190 | Медленный | Высокая | 0.15 сек |

**Генерируемые контуры:**
- **F0 контур** - динамическая интонация (восходящая/нисходящая)
- **Energy контур** - динамическая громкость
- **Duration** - фактор длительности сегментов

---

### 4. ArticulatoryModel (`articulatory_model.py`)

**Назначение:** Биомиметическая модель речевого тракта (source-filter)

**Принцип работы:**

#### Source (источник звука)
- **Голосовой источник:**
  - Периодический сигнал с частотой F0
  - Гармоники (2-7 гармоник)
  - Jitter (вариации F0 ~1%) - для естественности
  - Shimmer (вариации амплитуды ~3%) - для естественности
  - Асимметричная форма волны (быстрый подъём, медленный спад)

- **Шумовой источник:**
  - Для согласных звуков
  - Белый шум с фильтрацией

#### Filter (фильтр речевого тракта)
- **Формантные фильтры:**
  - F1, F2, F3 - резонансные частоты
  - Динамические вариации (2% для F1/F2, 1.5% для F3)
  - Медленная модуляция для естественности

**Синтез гласных:**
- Форманты для каждого гласного:
  - `a`: F1=700, F2=1200, F3=2500
  - `e`: F1=500, F2=1800, F3=2500
  - `i`: F1=300, F2=2200, F3=3000
  - `o`: F1=500, F2=900, F3=2500
  - `u`: F1=300, F2=700, F3=2200

### 5. ProsodyExtractor (`prosody_extraction.py`)

**Назначение:** Извлечение просодии из референсной речи

**Использует:**
- Praat (через `praat-parselmouth`)
- Извлекает:
  - F0 контур
  - Energy контур
  - Длительность сегментов

**Применение:**
- Перенос просодии с одного аудио на другое
- Обучение на примерах

---

### 6. SpeechSynthesizer (`speech_synthesizer.py`)

**Назначение:** Главный модуль, объединяющий все компоненты

**Основной метод:**
```python
synthesize_phrase(
    phrase: str,
    style: Optional[str] = None,  # Автоматически определяется если None
    base_f0: Optional[float] = None,
    duration_factor: Optional[float] = None,
    auto_detect_emotion: bool = True
) -> np.ndarray
```

**Процесс синтеза:**

1. **Определение эмоции** (если не указана):
   - Использует `EmotionDetector`
   - ML модель или rule-based

2. **Синтез базовой речи**:
   - TTS (если доступен) → естественный голос
   - Или артикуляторная модель → синтез из гласных

3. **Применение просодии**:
   - Генерация F0 и Energy контуров
   - Изменение темпа
   - Изменение громкости
   - Сглаживание переходов

4. **Возврат аудио**:
   - Нормализованный numpy массив
   - Готов для сохранения в WAV

## ⚙️ Как работает система

### Полный цикл синтеза

#### Шаг 1: Анализ текста
```
Вход: "Привет, как дела?"
      ↓
EmotionDetector анализирует:
  - Ключевые слова: "привет" → friendly
  - Пунктуация: "?" → friendly
  - ML модель: positive sentiment
      ↓
Результат: emotion='friendly', confidence=0.85
```

#### Шаг 2: Синтез базовой речи
```
Emotion: friendly
      ↓
Edge TTS выбирает голос: ru-RU-SvetlanaNeural (женский)
      ↓
Синтез: "Привет, как дела?" → аудио (естественный голос)
```

#### Шаг 3: Генерация просодии
```
Emotion: friendly
      ↓
ProsodyController генерирует:
  - F0 контур: 180-200 Гц, восходящая интонация
  - Energy контур: высокая громкость, плавные изменения
  - Duration: быстрый темп (factor=0.8)
```

#### Шаг 4: Применение просодии
```
Базовое аудио + Просодия
      ↓
- Time stretching (ускорение темпа)
- Energy modulation (изменение громкости)
- Smoothing (сглаживание)
      ↓
Результат: Естественная речь с эмоцией friendly
```

## 🔬 Технические детали

### Биомиметические элементы

#### 1. Source-Filter модель
Имитирует физиологический процесс производства речи:
- **Source** = голосовые связки (вибрация, F0)
- **Filter** = речевой тракт (резонансы, форманты)

#### 2. Естественные вариации
- **Jitter** - случайные вариации F0 (~1%)
- **Shimmer** - случайные вариации амплитуды (~3%)
- **Динамические форманты** - медленные изменения резонансов

#### 3. Плавные переходы
- **Crossfade** между сегментами (30 мс)
- **Gaussian smoothing** для контуров
- **Естественные паузы** между словами

### Просодические параметры

#### F0 (Fundamental Frequency) - Интонация
- **Нейтральный:** 150-170 Гц, плоский контур
- **Дружелюбный:** 180-200 Гц, восходящий контур
- **Строгий:** 120-140 Гц, нисходящий контур
- **Предупреждение:** 160-190 Гц, резкие изменения

#### Energy - Громкость
- **Нейтральный:** 0.7-0.9 (средняя)
- **Дружелюбный:** 0.8-1.0 (высокая)
- **Строгий:** 0.6-0.8 (низкая)
- **Предупреждение:** 0.9-1.0 (очень высокая)

#### Duration - Темп
- **Нейтральный:** factor=1.0 (нормальный)
- **Дружелюбный:** factor=0.8 (быстрый)
- **Строгий:** factor=1.3 (медленный)
- **Предупреждение:** factor=1.2 (медленный, но с акцентами)

## 💻 Использование

### Базовое использование

```python
from speech_synthesizer import SpeechSynthesizer

# Создание синтезатора
synthesizer = SpeechSynthesizer(
    sample_rate=16000,      # Частота дискретизации
    use_tts=True,           # Использовать TTS
    tts_engine='edge',      # Edge TTS (Microsoft)
    use_ml_emotion=True     # ML модель для эмоций
)

# Синтез (эмоция определяется автоматически!)
audio = synthesizer.synthesize_phrase("Привет, как дела?")

# Сохранение
synthesizer.save_audio(audio, 'output.wav')
```

### Продвинутое использование

```python
# Принудительное указание стиля
audio = synthesizer.synthesize_phrase(
    "Привет",
    style='friendly',           # Переопределить автоопределение
    base_f0=200.0,              # Кастомная F0
    duration_factor=0.9,        # Кастомный темп
    auto_detect_emotion=False   # Отключить автоопределение
)

# Перенос просодии из референсного файла
audio = synthesizer.transfer_prosody(
    "Новый текст",
    reference_audio_path='reference.wav'
)
```

### Настройка детектора эмоций

```python
from emotion_detector import EmotionDetector

# Только ML модель
detector = EmotionDetector(use_ml=True)

# Только rule-based
detector = EmotionDetector(use_ml=False)

# Определение эмоции
emotion, confidence = detector.detect("Я ТЕБЯ НЕНАВИЖУ!")
print(f"{emotion} ({confidence:.2f})")  # strict (0.83)
```

## 📝 Примеры

### Пример 1: Автоматическое определение эмоций

```python
from speech_synthesizer import SpeechSynthesizer

synthesizer = SpeechSynthesizer(use_tts=True, tts_engine='edge')

texts = [
    "Привет, как дела?",           # → friendly
    "Внимание! Опасность!",        # → warning
    "Стоп! Прекрати!",              # → strict
    "Спасибо за помощь!"            # → friendly
]

for text in texts:
    audio = synthesizer.synthesize_phrase(text)
    # Система сама определит эмоцию!
    synthesizer.save_audio(audio, f'{text[:10]}.wav')
```

### Пример 2: Разные стили одного текста

```python
text = "Привет, как дела?"

for style in ['neutral', 'friendly', 'strict', 'warning']:
    audio = synthesizer.synthesize_phrase(text, style=style)
    synthesizer.save_audio(audio, f'{style}.wav')
```

### Пример 3: Использование артикуляторной модели

```python
# Без TTS - использует биомиметическую модель
synthesizer = SpeechSynthesizer(use_tts=False)

audio = synthesizer.synthesize_phrase("Привет", style='friendly')
synthesizer.save_audio(audio, 'articulatory.wav')
```

## 🔍 Детали реализации

### Обработка сигнала

1. **Ресемплинг:**
   - Все аудио приводятся к единой частоте дискретизации
   - Используется `scipy.signal.resample`

2. **Нормализация:**
   - Аудио нормализуется к диапазону [-1, 1]
   - Защита от клиппинга

3. **Сглаживание:**
   - Gaussian фильтр для контуров
   - Crossfade для переходов

### Управление памятью

- Временные файлы автоматически удаляются
- Модели загружаются один раз при инициализации
- Аудио обрабатывается по частям для длинных текстов
