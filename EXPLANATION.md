# Как работает система: объяснение для начинающих

## 🎯 В чём смысл системы?

Система создаёт **синтезированную речь** (генерирует звук речи из текста), используя **биомиметическую модель** - то есть модель, которая имитирует реальный процесс производства речи человеком.

### Зачем это нужно?

1. **Для роботов**: чтобы робот мог говорить с разными эмоциями и интонациями
2. **Исследование**: изучение того, как работает человеческая речь
3. **Контроль**: возможность точно управлять параметрами речи (высота голоса, скорость, эмоция)

## 🧠 Как работает человеческая речь?

Когда человек говорит, происходит следующее:

1. **Голосовые связки вибрируют** → создают периодический звук (основная частота F0)
2. **Воздух проходит через речевой тракт** (горло, рот) → звук фильтруется
3. **Резонансы в речевом тракте** → создают форманты (F1, F2, F3)
4. **Положение языка, губ, челюсти** → меняет форманты → получаются разные звуки

**Пример:**
- Гласный "а" → язык низко, рот открыт → F1 высокий, F2 средний
- Гласный "и" → язык высоко, рот узкий → F1 низкий, F2 очень высокий

## 🔬 Как работает наша система?

### 1. Source-Filter модель (артикуляторная модель)

```
[Источник звука] → [Фильтр речевого тракта] → [Готовая речь]
```

#### Источник (Source):
- **Периодический сигнал**: имитирует вибрацию голосовых связок
  - F0 (fundamental frequency) = частота вибрации
  - Пример: F0 = 150 Гц → голосовые связки вибрируют 150 раз в секунду
  
- **Шумовой сигнал**: для согласных (п, т, к, с, ш)
  - Турбулентный поток воздуха создаёт шум

#### Фильтр (Filter):
- **Формантные резонаторы**: имитируют резонансы речевого тракта
  - F1, F2, F3 = три основные резонансные частоты
  - Каждая форманта = один резонатор (как гитарная струна)
  
**Физический смысл:**
- F1 связан с высотой языка (вертикальное положение)
- F2 связан с передне-задним положением языка
- F3 связан с формой глотки

### 2. Управление просодией

**Просодия** = мелодия, ритм, громкость речи (не сами звуки, а как они произносятся)

#### Параметры:
- **F0 (интонация)**: высота голоса
  - Высокий F0 → дружелюбно, вопрос
  - Низкий F0 → строго, утверждение
  
- **Energy (громкость)**: амплитуда вибрации
  - Высокая energy → громче, эмоциональнее
  
- **Duration (темп)**: скорость речи
  - Медленнее → важнее, строже
  - Быстрее → дружелюбнее, неформальнее

#### Стили речи:
```python
'neutral'   → F0=150 Гц, средняя скорость, средняя громкость
'friendly'  → F0=180 Гц, быстрее, громче
'strict'    → F0=120 Гц, медленнее, громче
'warning'   → F0=200 Гц, медленнее, очень громко
```

### 3. Перенос просодии

**Идея**: взять интонацию из одной речи и применить к другой

**Как работает:**
1. Извлекаем из референсной речи:
   - F0 контур (как меняется высота голоса)
   - Energy контур (как меняется громкость)
   - Длительность сегментов
   
2. Применяем эти параметры к синтезированной речи

**Пример:**
- Референс: "Привет!" (сказано радостно)
- Целевая фраза: "Как дела?"
- Результат: "Как дела?" звучит с той же радостной интонацией

## 🔬 Физиологический смысл параметров

### F0 (Fundamental Frequency)
- **Что это**: Частота вибрации голосовых связок
- **Физиология**: Напряжение мышц гортани + подглоточное давление
- **Влияние**: Высота голоса, интонация
- **Примеры**:
  - Мужской голос: 100-150 Гц
  - Женский голос: 150-250 Гц
  - Детский голос: 250-400 Гц

### Форманты (F1, F2, F3)
- **Что это**: Резонансные частоты речевого тракта
- **Физиология**: Зависят от формы и размеров речевого тракта
- **Влияние**: Определяют, какой звук получается
- **Примеры**:
  - "а": F1=730, F2=1090, F3=2440 Гц
  - "и": F1=270, F2=2290, F3=3010 Гц
  - "у": F1=300, F2=870, F3=2240 Гц

### Energy (Энергия)
- **Что это**: Амплитуда вибрации голосовых связок
- **Физиология**: Сила выдоха + напряжение связок
- **Влияние**: Громкость речи
- **Примеры**:
  - Шёпот: низкая energy
  - Обычная речь: средняя energy
  - Крик: высокая energy

### Duration (Длительность)
- **Что это**: Время произнесения звука
- **Физиология**: Скорость артикуляторных движений
- **Влияние**: Темп речи
- **Примеры**:
  - Быстрая речь: короткие duration
  - Медленная речь: длинные duration
  - Эмфаза: ещё длиннее

## 🆚 Отличия от обычных TTS систем

### Обычные TTS (Text-to-Speech):
- Используют нейронные сети
- "Чёрный ящик" - непонятно, как работает
- Сложно управлять параметрами
- Требуют много данных для обучения

### Наша система:
- ✅ Физически интерпретируемая модель
- ✅ Понятно, как работает каждый компонент
- ✅ Легко управлять параметрами (F0, форманты, стили)
- ✅ Не требует обучения на данных
- ✅ Можно точно контролировать просодию

## 📈 Преимущества биомиметического подхода

1. **Контроль**: Можно точно задать любой параметр
2. **Понимание**: Видно связь между физиологией и звуком
3. **Гибкость**: Легко добавлять новые стили и параметры
4. **Исследование**: Помогает изучать речь

## 🎓 Что можно улучшить?

Текущая система - прототип. Можно добавить:

1. **Больше фонем**: не только гласные, но и согласные
2. **Динамику**: плавные переходы между звуками
3. **Эмоции**: более сложные модели эмоций
4. **Языки**: поддержку разных языков
5. **Real-time**: оптимизацию для работы в реальном времени

## 🔍 Пример кода с объяснениями

```python
from speech_synthesizer import SpeechSynthesizer

# Создаём синтезатор
synthesizer = SpeechSynthesizer(sample_rate=16000)
# sample_rate = частота дискретизации (16000 Гц = 16000 отсчётов в секунду)

# Синтезируем фразу
audio = synthesizer.synthesize_phrase(
    "Привет",           # Текст для синтеза
    style='friendly'    # Стиль речи
)

# Что происходит внутри:
# 1. Извлекаются гласные: ['i', 'e']
# 2. Для каждого гласного:
#    - Генерируется источник (F0 = 180 Гц для friendly)
#    - Применяется формантный фильтр (F1, F2, F3 для каждого гласного)
#    - Применяется просодия (F0 контур, energy)
# 3. Сегменты объединяются
# 4. Результат сохраняется

synthesizer.save_audio(audio, 'output.wav')
```

3. **Просодия**: мелодия и ритм речи
4. **Биомиметика**: имитация реального процесса производства речи
5. **Контроль**: возможность точно управлять каждым параметром
