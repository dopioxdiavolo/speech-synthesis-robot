# Мультимодальная система синтеза речи для социального робота

Учебно-исследовательский прототип мультимодальной системы синтеза речи, объединяющей:
- Физиологически обоснованную модель голосовых связок (source-level)
- Визуальную экспрессию (мимику робота)
- Координацию голоса и мимики через контроллер поведения

Система основана на упрощённой биомиметической (source–filter / articulatory-inspired) модели речевого тракта с возможностью адаптивного управления и переноса просодии.

## Описание проекта

Проект реализует мультимодальную систему синтеза речи для социального робота, использующую физиологически интерпретируемые параметры. Система объединяет:
- **Голос**: модель голосовых связок с параметрами F0, jitter, shimmer, phonation type
- **Мимика**: визуализация состояния экспрессии робота (neutral, friendly, strict, warning)
- **Поведение**: координация голоса и мимики через BehaviorController

Система основана на source-filter модели речевого тракта и поддерживает управление просодическими характеристиками речи.

## Основные компоненты

### 1. Модель голосовых связок (`vocal_folds.py`) ⭐ НОВОЕ

Физиологически обоснованная модель фонации на уровне источника (source-level):

- **F0** (fundamental frequency): основная частота вибрации голосовых связок
- **Jitter**: вариабельность F0 между циклами (норма: 0.5-1.5%)
- **Shimmer**: вариабельность амплитуды между циклами (норма: 3-5%)
- **Phonation Type**: тип фонации
  - `modal`: нормальная фонация
  - `breathy`: придыхательная фонация
  - `pressed`: сжатая фонация

**Физиологический смысл:**
- Параметры отражают физические свойства голосовых связок
- Jitter и shimmer моделируют естественные микро-вариации
- Тип фонации зависит от степени смыкания связок

### 2. Визуализация мимики (`facial_expression.py`) ⭐ НОВОЕ

Модуль для отображения состояния экспрессии робота:

- **Состояния**: neutral, friendly, strict, warning
- **Методы визуализации**:
  - `matplotlib`: детальная графическая визуализация
  - `pygame`: интерактивная анимация
  - `ascii`: ASCII-арт в терминале
  - `emoji`: простые смайлики

### 3. Контроллер поведения (`behavior_controller.py`) ⭐ НОВОЕ

Координирует состояние голоса и мимики:

- Маппинг стилей речи на параметры голоса и мимики
- Учёт внутреннего состояния робота (energy, stress, mood)
- Согласованное поведение голоса и мимики

### 4. Биомиметическая модель речевого тракта (`articulatory_model.py`)

Реализует source-filter модель речи:

- **Source (источник)**:
  - Периодический сигнал (voice source, F0) - моделирует вибрацию голосовых связок
  - Шумовая компонента для согласных - моделирует турбулентный поток воздуха

- **Filter (фильтр)**:
  - Формантная модель (F1, F2, F3) - резонансы речевого тракта
  - Управление параметрами артикуляции через формантные частоты

**Физиологический смысл параметров:**
- **F0** (fundamental frequency): частота вибрации голосовых связок
- **F1, F2, F3**: резонансные частоты речевого тракта, зависящие от положения языка, губ, челюсти
- **Bandwidth**: затухание формант, связанное с потерями энергии в речевом тракте

### 5. Управление просодией (`prosody_controller.py`)

Реализует управление просодическими параметрами:

- **F0 (интонация)**: управление мелодией речи
- **Energy (громкость)**: управление амплитудой
- **Duration (темп)**: управление скоростью речи
- **Паузы**: управление паузами между сегментами

**Режимы речи:**
- `neutral` - нейтральный
- `friendly` - дружелюбный
- `strict` - строгий
- `warning` - предупреждение

### 6. Извлечение просодии (`prosody_extraction.py`)

Использует parselmouth (Praat API) для извлечения просодических характеристик из референсной речи:

- F0 contour (мелодия, интонация)
- Energy contour (громкость)
- Duration (длительность сегментов)

### 7. Основной синтезатор (`speech_synthesizer.py`)

Объединяет все компоненты мультимодальной системы:

- Синтез фраз с заданным стилем
- Перенос просодии из референсной речи
- Управление просодическими параметрами
- **Интеграция модели голосовых связок**
- **Визуализация мимики в реальном времени**
- **Координация голоса и мимики через BehaviorController**

## Установка

- Python 3.10+ (рекомендуется Python 3.10 или 3.11)
- Установленные зависимости (см. `requirements.txt`)

### Установка зависимостей

**Полная установка (рекомендуется):**
```bash
pip install -r requirements.txt
```

**Или установка по отдельности:**
```bash
pip install numpy scipy torch soundfile praat-parselmouth
```

**Важно:** Используйте пакет `praat-parselmouth`, а не `parselmouth`! 
- `praat-parselmouth` - правильный пакет для работы с Praat (совместим с Python 3.12+)
- `parselmouth` - другой пакет для рекламных платформ (не нужен)

См. [документацию praat-parselmouth](https://parselmouth.readthedocs.io/).

## Использование

### Мультимодальный синтез с визуализацией мимики ⭐ НОВОЕ

```python
from speech_synthesizer import SpeechSynthesizer

# Создание синтезатора с мультимодальной системой
synthesizer = SpeechSynthesizer(
    sample_rate=16000,
    use_tts=True,  # TTS для нормальной речи
    tts_engine='edge',
    use_vocal_folds=True,  # Модель голосовых связок
    facial_render_method='matplotlib'  # или 'pygame', 'ascii', 'emoji'
)

# Синтез с автоматическим определением эмоции и визуализацией мимики
audio, facial_state = synthesizer.synthesize_phrase(
    "Привет, как дела?",
    show_facial_expression=True
)

# Сохранение результата
synthesizer.save_audio(audio, 'output.wav')
print(f"Состояние мимики: {facial_state.value}")
```

**Методы визуализации мимики:**
- `matplotlib`: детальная графическая визуализация (требует `pip install matplotlib`)
- `pygame`: интерактивная анимация (требует `pip install pygame`)
- `ascii`: ASCII-арт в терминале (не требует установки)
- `emoji`: простые смайлики (не требует установки, по умолчанию)

### Базовое использование с естественным голосом

```python
from speech_synthesizer import SpeechSynthesizer

# Создание синтезатора с Edge TTS (естественный голос)
synthesizer = SpeechSynthesizer(
    sample_rate=16000,
    use_tts=True,
    tts_engine='edge'  # Edge TTS (Microsoft) - качественный и бесплатный
)

# Синтез фразы в определённом стиле
audio, facial_state = synthesizer.synthesize_phrase(
    "Привет, как дела?", 
    style='friendly'
)

# Сохранение результата
synthesizer.save_audio(audio, 'output.wav')
```

**Установка Edge TTS:**
```bash
pip install edge-tts
```

### Синтез с внутренним состоянием робота ⭐ НОВОЕ

```python
# Влияние внутреннего состояния на голос и мимику
audio, facial_state = synthesizer.synthesize_phrase(
    "Привет!",
    style='neutral',
    internal_state={
        'energy': 1.5,  # Высокая энергия → выше F0
        'stress': 0.3,  # Низкий стресс → меньше jitter
        'mood': 'positive'  # Положительное настроение → friendly мимика
    }
)
```

## Биомиметические элементы модели

Система использует следующие физиологически интерпретируемые элементы:

1. **Source-Filter архитектура**: соответствует физическому процессу производства речи
   - Источник: вибрация голосовых связок + турбулентный поток
   - Фильтр: резонансные свойства речевого тракта

2. **Модель голосовых связок** ⭐ НОВОЕ:
   - F0: частота вибрации, зависит от длины, массы и натяжения связок
   - Jitter: микро-вариации F0 из-за нелинейной динамики
   - Shimmer: вариации амплитуды из-за изменений потока воздуха
   - Phonation type: степень смыкания связок (modal/breathy/pressed)

3. **Формантные резонаторы**: моделируют резонансы речевого тракта
   - F1: связан с высотой языка (вертикальное положение)
   - F2: связан с передне-задним положением языка
   - F3: связан с формой глотки и ротовой полости

4. **Просодические параметры**:
   - F0: отражает напряжение голосовых связок и подглоточное давление
   - Energy: связана с амплитудой вибрации и потоком воздуха
   - Duration: зависит от артикуляторной скорости

5. **Мультимодальная экспрессия** ⭐ НОВОЕ:
   - Координация голоса и мимики через BehaviorController
   - Визуализация состояния экспрессии в реальном времени
   - Учёт внутреннего состояния робота (energy, stress, mood)

## Применимость в робототехнике

Система может быть использована в следующих приложениях:

1. **Социальные роботы**: мультимодальный синтез речи с адаптацией к контексту взаимодействия
2. **Эмоциональная выразительность**: изменение просодии и мимики для передачи эмоций
3. **Персонализация**: перенос просодических характеристик от пользователя к роботу
4. **Мультимодальная коммуникация**: согласованное выражение через голос и мимику
5. **ROS/ROS2 интеграция**: модуль может быть интегрирован как ROS-нода для робототехнических систем

### Интеграция с ROS (опционально)

Для интеграции с ROS можно создать ноду:

```python
import rospy
from std_msgs.msg import String
from speech_synthesizer import SpeechSynthesizer

def speech_callback(msg):
    phrase = msg.data
    audio, facial_state = synthesizer.synthesize_phrase(phrase, style='neutral')
    # Публикация аудио
    # Публикация состояния мимики
    pub_expression.publish(facial_state.value)

rospy.init_node('speech_synthesizer')
synthesizer = SpeechSynthesizer(
    use_vocal_folds=True,
    facial_render_method='emoji'  # или другой метод
)
rospy.Subscriber('/speech/text', String, speech_callback)
pub_expression = rospy.Publisher('/robot/expression', String, queue_size=10)
rospy.spin()
```
